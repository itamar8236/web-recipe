# AGENTS.md

This file is the entry point for coding agents other than Claude Code (Codex, Cursor,
and others that read `AGENTS.md`).

**All project rules live in [`CLAUDE.md`](CLAUDE.md). Read it fully before making any
change and follow it exactly.** It is the single source of truth for the project
overview, layout, commands, git workflow, and conventions. Do not duplicate its
content here; update `CLAUDE.md` instead.

Shared skills (step-by-step playbooks) live in [`.agents/skills/`](.agents/skills/).
Read the matching `SKILL.md` before starting that kind of task:

- `git-workflow`: branching, commits, pushing, and pull requests
- `new-feature`: implementing a feature across backend and frontend
- `bug-fix`: reproducing and fixing a bug
- `frontend-ui`: building or changing UI in `frontend/`
